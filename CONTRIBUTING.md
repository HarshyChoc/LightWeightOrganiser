# Contributing to Lightweight Organiser

Start with the setup and validation commands in the README. Open an issue describing the behavior you want to improve before a large change. Keep pull requests focused and include steps to reproduce the problem and evidence that the fix works.

Use synthetic fixtures and include regression coverage for behavior changes. Do not commit credentials, local app data, recordings, generated caches or customer files. Preserve notices when incorporating third-party code. Contributions are made under the repository's MIT license unless a file explicitly states otherwise.
